# Phase 1 - Task 01: Business Description And Project Charter

## User Prompt

```text
I want to build Travel TVB, a multilingual tour guide and booking platform.
The system must let travelers browse tours, read travel content, chat with an AI assistant, create bookings, pay with VNPay, and manage their account.
Start from the business description and prepare the first SDLC planning report.
```

## AI Understanding

AI identified Travel TVB as a customer-facing travel platform with six main capability areas:

- Tour discovery and tour detail pages.
- Customer identity and account access.
- Booking management.
- VNPay payment processing.
- Travel content and FAQ management.
- AI chatbot support for tour guidance.

The project was treated as a new production system that needs independent service ownership, clear delivery phases, and measurable business success criteria.

## AI Work Report

AI created the initial project charter:

- Defined the product vision: one platform for tour browsing, AI-assisted travel guidance, booking, and online payment.
- Identified primary users: visitors, registered customers, administrators, and system operators.
- Defined core business workflows: browse tours, view details, ask AI, register or log in, book a tour, pay, view booking status, and read travel content.
- Proposed a 7-phase SDLC path from planning to operations.
- Identified high-level technology choices: React frontend, API gateway, NestJS services, FastAPI AI service, Strapi content service, PostgreSQL, RabbitMQ, ChromaDB, Redis, and Kubernetes.

## Deliverables

- Project charter summary.
- Initial stakeholder map.
- Business workflow list.
- SDLC phase outline.

## Validation Notes

The task was considered complete when the system goal, user groups, business workflows, and SDLC direction were clear enough to begin requirements analysis.
