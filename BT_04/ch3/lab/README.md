# Lab 3 — GitHub Copilot

Worked solutions for the Chapter 3 labs. The running example is the
**geometric mean**. These labs use GitHub Copilot inside the IDE; the code
here is the result. It is plain Python and needs **no API key**.

| File | Lab | What it does |
|------|-----|--------------|
| `lab31_geometric_mean.py` | 3.1 | Variadic geometric-mean function (chat + inline suggestions) |
| `lab32_geometric_mean_two.py` | 3.2 | Two-number version with full type hints |
| `lab33_bugfix_geometric_mean.py` | 3.3 | Find & fix a bug — exponent `1/2` should be `1/3` |

## Run

```
python lab31_geometric_mean.py
python lab32_geometric_mean_two.py
python lab33_bugfix_geometric_mean.py
```

No API key needed. Discussion of how Copilot was used is in
`../BaoCao_Chuong3_GitHub_Copilot.docx`.
